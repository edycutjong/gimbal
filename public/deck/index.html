The problem

Prescribed like a drug.
Measured like a rumour.

Gaze-stabilization exercise carries parameters — head frequency, peak velocity, duration, repetitions per day. The clinic sets all of them and then measures none of them, because the exercise happens at a kitchen table six days out of seven.

The only instrument the clinic currently has

“How did the home exercises go?”

“Yeah — most days, I think.”

Answered from memory, in minutes-claimed. That sentence is the entire adherence evidence base for the exercise on the left.

Every tool in this space watches, asks, or chats. Nothing measures the delivered dose of the prescribed treatment.

The insight

A rep counter rewards the exact behaviour that makes the therapy useless.

Solid is a credited cycle, an empty outline a refused one — the encoding is shape, so it survives greyscale and a bad projector. Schematic, drawn rather than recorded: no bench recording exists yet.

Doing it too slowly is not a partial dose.
It is a different, non-therapeutic activity.

The VOR adapts to a retinal-slip error signal. Below the prescribed velocity the error signal that drives the adaptation is not produced, so the twenty cycles on the left are not eighty percent of a dose. They are none of it.

So Gimbal counts seconds in the band, never repetitions. A refused cycle contributes exactly 0.000 s.

There is no celebration, because a reward loop that encourages more of a symptom-limited therapy is clinically backwards. No streaks. No badges. No XP. No daily-goal confetti. src/ui/copy.ts · 'low-confidence'

The biggest technical risk in the build is head-pose fidelity at 2 Hz on a cheap webcam. Gimbal answers it by refusing to emit rather than by smoothing.

Cover part of your face or dim the room and the instrument declines to produce a number it cannot stand behind.

Precedence, when more than one holds

  • face-lostthe instrument could not see
  • low-confidencethe instrument does not trust itself
  • too-slow / too-fastthe measurement is good and the motion missed the prescription
  • off-cadence… and missed the pacing tempo

The order runs from instrument failure to patient motion, in that direction, because reporting an instrument failure as a patient failure would be the wrong way round.

Six outcomes total: ok, plus five named refusals — and every refused cycle contributes exactly 0.000 s.

All six live in src/dsp/score.ts — the only module allowed to decide — and the precedence above is the order in which it evaluates them.

How it works — one 30 Hz loop, entirely inside the tab

Smooth. Differentiate. Then correct the bias.

We differentiate with the one operator whose bias has a closed form — so the correction is derived on paper and published, not tuned until the demo looked right.

Latency, stated rather than hidden

The symmetric smoother costs 2 frames and the difference 1 more, so ω is reported 3 frames — about 100 ms — behind the head that produced it. One sweep at 2 Hz is 250 ms, so the coaching still lands inside the same head turn.

The eyes-free coach

A Web Audio click train sets the tempo and one oscillator's pitch bends as peak velocity leaves the band — so the primary feedback loop works with the screen off. Output-only: the Permissions-Policy denies the microphone.

The protocol card — typed by the patient

Every clinical threshold enters at the gate and nowhere else. src/dsp/score.ts contains no numeric literal other than 0 and 1000, and a test greps the module and fails if one appears.

A 3-point central difference on a sinusoid reports exactly sin(2πfT)/(2πfT) of the true peak — 0.9710 at 2 Hz and 30 fps, a 2.90 % under-read, corrected by ×1.0299. A unit test asserts the identity at 1.0, 1.5, 2.0 and 2.5 Hz, and asserts the correction is applied once, not twice.

Vite 5 + vanilla TypeScript. No framework, no SSR, no server runtime, no LLM. The only judged code path is a hot loop, and a re-render model is a hazard inside one.

Calibrated honesty — the number that is not here

No bench-agreement figure appears anywhere in this repository, because none has been recorded.

Agreement vs. an independent sensor

README.md and DEMO.md both say so outright, and no document in the repository quotes an agreement figure at all. There is no quieter version somewhere that says something better.

Also provisional, and labelled in the code

Two instrument thresholds — qFloor and deadbandFraction — are set from a tracking spike that does not exist yet. PROVISIONAL_FROM_SPIKE in src/dsp/limits.ts names exactly which ones, and no claim is made that they are calibrated.

Exactly what would produce the number

1
A phone gyroscope logged rigidly at the temple while the webcam runs Gimbal on the same head, in the same session.
2
The two traces aligned by cross-correlation, so the comparison does not depend on either clock being right.
3
Compared per cycle — peak against peak — and reported as a bench validation: single subject, one camera, one lighting condition. Never as a study.

The tolerance was fixed before the measurement: 6.0 °/s, chosen below the 7.3 °/s size of the bias-correction effect, so deleting the correction fails the gate.

If the recording comes back worse than 6.0, we publish the measured number and lower the prescribed band — never raise the tolerance.

There is likewise no user count, no clinician count, no adoption figure and no testimonial in this deck, because there are none. In a rubric that scores Safety and Research Foundation, naming your own unmeasured quantity is worth more than a confident invented one.

Accessibility is the design constraint, not a checklist

During the exercise the patient's eyes are on the optotype and cannot reach a dial — so the coaching signal had to be audio, which means the primary feedback loop works with the screen off. The two zone colours are deliberately near-iso-luminant (1.26 : 1 in dark) so the ring cannot strobe in the peripheral field of a photophobic user. Nothing renders below 15 px anywhere, at any viewport, in any state.

Deliberate non-features — each absence is load-bearing

  • any LLMthe output is a count. A generative model would import the whole hallucination surface into a submission judged on safety
  • iris / gaze trackingunsolved on commodity webcams at 250 °/s, and its error is confounded with the rotation being measured
  • server · account · exporteach falsifies the on-device claim. A share link is an upload with better manners
  • an exercise libraryone exercise done devastatingly beats six done adequately
  • posture detectionunverifiable from a face mesh. Building it means claiming it — so stage is self-attested and the report says so
  • streaks · badges · XPincentivising more of a symptom-limited therapy is clinically backwards

The anti-gaming property is structural, not cryptographic: the only way to fake the dose is to perform the therapy.
